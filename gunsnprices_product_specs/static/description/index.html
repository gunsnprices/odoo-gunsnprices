Firearm & Ammo Specs

Caliber, model, magazine capacity, barrel length, rounds per box and cost per round on your products, read from the product name.

For gun shops, ammo stores and outdoor retailers selling with Odoo. Free, LGPL-3.

What the module adds

  • A Specs tab on products: firearm or ammo, brand, model family, model, generation, caliber, other calibers, caliber class, magazine capacity, barrel length (in), rounds per box, cost per round.
  • A Fill Specs from Name button on the product form and the same action in the Actions menu of product lists, for one product or thousands.
  • Cost per round for ammunition: sales price divided by rounds per box, updated when the price changes. Sort and filter by it.
  • 293 calibers (203 rifle, 60 handgun, 13 rimfire, 8 shotgun, 6 airgun, 3 muzzleloader), most common first, with the spellings retailers use.
  • Search and group products by caliber, caliber class, brand and model family; optional list columns.
  • Settings: overwrite filled-in values or not, and fill specs automatically when products are created or imported.

Settings

How it works

  • Only empty fields are filled unless you turn on "Overwrite Existing Specs". A field is never cleared: if the name gives nothing for it, it keeps its value.
  • Import with any caliber spelling. A CSV column with "9mm Luger", "5.56 NATO" or "12ga" is matched to the right caliber.
  • Runs inside Odoo. No external service, no account, no API key. Product names are not sent anywhere.
  • Nothing to install with pip. The title parser (the gunsnprices Python package, MIT) and its caliber and model data (CC BY 4.0) are bundled in the module. If a newer 0.1.x release of the package is installed on the server, the module uses it.
  • Depends only on the Product module. Tested on Odoo 18 together with Sales, Inventory, Purchase, Point of Sale and eCommerce. Specs are stored on the product template; variant forms show them too.
  • Not for Odoo Online: like every app with Python code, it needs Odoo.sh or an on-premise server.
